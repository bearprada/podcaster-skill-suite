# Project plan

## Current scope

Establish [agent guidelines](AGENTS.md) and [project memory](PROJECT_MEMORY.md). This documentation rollout does not complete the skills/product backlog.

## Work queue

Use approved requests and remote issues/PRs as the backlog. Record item ID, priority, owner, dependency IDs, branch/worktree, acceptance test cases, verification command/results, status and next action. Preserve pending verification/review and continue independent work.

## Rollout exit criteria

Validate guidance coverage, local links and `git diff --check`; commit only rollout documents and publish to `origin/master`. Confirm the containing commit SHA with `git ls-remote origin refs/heads/master`.

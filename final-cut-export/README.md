# Final Cut Pro export

Import `槍擊埋下的23年真相-final-cut.fcpxml` in Final Cut Pro with **File > Import > XML**.

The XML contains two projects:

1. **Reference Render - 29.76s** — the finished vertical MP4, original audio excerpt, and editable caption clips.
2. **Editable Layers - rebuild animation** — separate portrait/background layers, original audio excerpt, and editable caption clips. Use this project to rebuild the motion with Final Cut Pro keyframes or Motion.

Keep the `media` folder beside the XML. If Final Cut reports offline media, relink the clips to that folder.

The visual title treatment is supplied in the MP4 reference render. The editable project exposes the caption text and source layers; the circle mask, title styling, and smooth keyframes can be adjusted in Final Cut Pro or Motion.
